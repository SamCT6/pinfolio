# Display preferences update

More now includes text size and card size preferences. Text size changes pin names and metadata. Card size changes the actual width and number of cards per row across Collection, Catalog, Friends, and Traders (where those pages use the shared pin grid). Preferences are saved locally and applied when the app starts.

The old `pinfolio-pin-image-size` setting is read as a fallback so existing users keep a sensible starting preference.
